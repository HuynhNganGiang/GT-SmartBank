Giới thiệu GT SmartBank

Ngân hàng số thông minh
cho trải nghiệm tài chính hiện đại

GT SmartBank là hệ thống ngân hàng số mô phỏng theo mô hình thực tế, tích hợp quản lý khách hàng, tài khoản, giao dịch, tiết kiệm, chi nhánh ATM, xác thực JWT, Swagger API và trợ lý GT Bot.

Tầm nhìn

Trở thành nền tảng ngân hàng số thông minh, an toàn và dễ sử dụng, giúp người dùng tiếp cận các dịch vụ tài chính mọi lúc, mọi nơi.

Sứ mệnh

Ứng dụng ASP.NET Core Web API, SQL Server và giao diện hiện đại để xây dựng một sản phẩm demo ngân hàng số hoàn chỉnh, minh bạch và bảo mật.
